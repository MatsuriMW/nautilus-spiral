## 用到哪个开哪个

| 功能 | 要先有什么 | 在哪开 | 默认 |
|---|---|---|---|
| 把 macOS 日历的事件排进来 | Xcode 命令行工具（`xcode-select --install`）；第一次用时允许 Obsidian 访问日历 | 「读 macOS 日历」 | 关 |
| 把 Google 日历的事件排进来 | 一个 Google 账号，和你自己在 Google Cloud 里建的 OAuth 客户端，见「📅 Google 日历」 | 「读 Google 日历」 | 关 |
| ▶ 开始做时顺带开 Raycast Focus | Raycast | 「同时开 Raycast 专注」 | 开 |
| 螺旋内圈画出 Agent 干活的时段和 token | 本机用过 Claude Code、Codex、WorkBuddy 或 DeepSeek Harness（读它们留在本机的会话日志 / 本机统计接口）。在「🤖 主力 Agent 和要追踪的 Agent」里选一个主力、再开上别的你也用的，没用过的开着也不碍事 | 「显示人机协作」 | 开，四个都开 |
| 提醒发到 Discord | 你自己有一个发 Discord 的命令行脚本，放在 `~/.local/bin/notify-discord`，调用方式是 `notify-discord --as <显示名> <频道> <内容>` | 「提醒发到 Discord 的哪个频道」 | 空 |

## 日记里的写法

```markdown
- 08:00-08:30 早饭
- 12:00-13:00 午饭
- 14:30-15:30 和小李开会
- DONE 07:30-08:00 跑步
- **09:40** 想到一个选题：时间预算
- DOING 09:10 写稿 2h 40%
- TODO 剪视频 1.5h ⭐
- TODO 回邮件 20m
- TODO 整理笔记
- WAITING 等合同回来 1h
- TODO 16:00 打电话给妈妈
```

早上 10 点打开螺旋，插件读出来的是：

| 时间 | 事项 | 说明 |
|---|---|---|
| 09:10–10:00 | 写稿 | 已经做掉的一段，画得淡一些 |
| 10:00–11:12 | 写稿 | 预估 2h、写了 40%，还剩 1h12m |
| 11:12–12:00、13:00–13:42 | 剪视频 | 被午饭隔成两段（每段都不短于 25 分钟才切）；带 ⭐，画成红色 |
| 13:42–14:02 | 回邮件 | |
| 14:02–14:17 | 整理笔记 | 没写时长，按默认 15 分钟 |
| 16:00–16:15 | 打电话给妈妈 | 写了时刻的待办当事件处理，钉在 16:00 |
| — | 等合同回来 | WAITING：挂起，不排、不占容量 |

容量条下面只有两行，左边一列图标：「📋 已计划 3h17m · 余量 8h28m · 剩余 64%」和「🤖 协作 2h10m · 6.3M tok」（一天按 8 点到 24 点算；没用 Agent 的日子没有第二行）。可安排的时间正在流逝时，📋 换成一闪一闪的 🔥。细账都在悬停提示里：鼠标停在第一行上看可安排和事件两笔预算、按以往的校准、复习、游戏、有没有记录；停在第二行上看各 Agent、工时、token 的拆分和各个大方向。每个数字的意思见「容量条上的数字」。专注中、吃饭中这种正在发生的事各另起一行。

### 每一行会被认成什么

| 写法 | 认成 | 例子 |
|---|---|---|
| 带时间段的列表项 | **固定事件**（黄色） | `14:00-15:30 开会`、`3点到5点 上课`、`9点半-10 通勤` |
| 任务关键词或复选框 | **待办**（蓝色） | `TODO 回邮件 20m`、`- [ ] 回邮件 20m` |
| 待办里写了一个时刻 | **钉住的待办**，按事件处理 | `TODO 16:00 打电话 15m` |
| `**07:37**` 开头、不是任务 | **记录点**，螺旋上画一个小点 | `**07:37** 起床` |
| 其它普通列表项 | 不参与排程 | |

关键词和复选框：

| 状态 | 写法 |
|---|---|
| 待办 | `TODO`、`LATER`、`[ ]` |
| 进行中（排在最前） | `DOING`、`NOW`、`IN-PROGRESS`、`[/]` |
| 暂停（停一下，照常排，接着做时扣掉做过的） | `PAUSED` |
| Agent 会话停在半路（和暂停一样排；Agent Deck 按会话状态自动切，见「任务行下面的进度条」） | `TOREVIEW`（等你看）、`NEEDOK`（等你点「允许」）、`ERRORED`（报错停了）、`HITLIMIT`（撞了用量限额）、`QUEUED`（撞限额后已排队，到点自动续跑）、`DELEGATED`（委派给 Agent 了，会话在跑；停下来照会话状态切，再动起来回 `DOING`） |
| 搁置（短期不推，不排、不占容量） | `SUSPENDED`、`WAITING`、`WAIT` |
| 完成 | `DONE`、`[x]` |
| 取消（直接忽略） | `CANCELED`、`CANCELLED`、`FAILED`、`[-]` |

一次列好几件待办，可以不用每行写 `TODO`：先写一行 `- todos：`（大小写、全角半角冒号都认），下面直接挂着的那一层子条目没写关键词的都当 `TODO`。改状态时关键词才真正写进那一行（`1. 写稿` → `1. DOING 14:05 写稿`）；子条目自己写了关键词的照它自己的，再往下一层是细节，不算任务。TODOseq（本地补丁版）和块去向认的是同一套写法。

```markdown
- todos：
	1. 写稿 2h
	2. 剪视频 1.5h
		- 先剪开头那段（细节，不算任务）
	3. DOING 10:20 回邮件
```

时长写在任务文字里任何位置都行：`30m`、`45min`、`2h`、`1.5h`、`2h30m`、`半小时`、`两小时`、`一个半小时`、`25～30分钟`（写成范围的按上限算）。

进度写成 `40%`、`1/3`、`三分之一`、`一半`。写了进度，剩余时间按进度算：`3h 40%` 还剩 1h48m。

重要标记：任务里出现 `[[important]]`、`[[重要]]`、`⭐`、`‼️`（设置里可改）就画成红色。

### 紧跟在关键词后面的时间是「记录」

| 写法 | 意思 |
|---|---|
| `DOING 14:05 写稿` | 14:05 开始做的 |
| `DONE 18:02 写稿` | 18:02 做完 |
| `DONE 14:00-15:30 写稿`、`DONE 10-12 写稿` | 实际做在这一段 |

这些是手写的补记，优先级最高。没写的话，插件会自己记：看到任务变成 DOING 开始计时，变成 DONE 记下完成时刻。

### 凌晨算前一天

凌晨 1 点写的 `01:30-02:00 收尾` 属于前一天的日记，画在那一天的夜里。几点之前算前一天，由设置里的「日记日期分界」决定（默认 08:00）。

这一项按 24 小时制的时刻填：`08:00`、`4:30`、`23:30` 都行，只写一个数也行（`8` 就是 08:00）。填得不对输入框会变红，离开时退回原来的值。

配套的插件算「今天是哪一篇日记」时读的也是这一项，改了它们一起跟着变：日记整理的「整理今天的日记」和「归档记一笔」、块去向的「发送到今天 / 明天」、任务提醒、Telegram Companion。

## 排程规则

1. **从哪开始排**：今天从「现在」开始；以后的日子从一天的开始；过去的日子没做完的全算「没做完」。
2. **事件先占位**：时间段内的固定事件和钉住的待办先占掉，剩下的空档才分给待办。
3. **排队顺序**：DOING 的排最前，其余按日记里从上到下的顺序。
   - **几件 DOING 并行**：一起从现在开始，重叠在同一段时间里，只占最长那件的时间。三件各 25 分钟只占 25 分钟，不是 75 分钟。螺旋上每件画在自己的那条线上，沿螺旋错开一点。其余待办排在这段之后。设置里关掉「DOING 并行排」，就恢复成首尾相接。
4. **找空档**：每件待办放进最早放得下的空档。
   - **短任务整块放**：一个空档放不下，就跳到下一个够大的空档，不会被切成「18 分钟 + 2 分钟」这样的碎片。
   - **小任务往前补位**：被跳过的空档留给后面的小任务。比如 10:30 有站会，40 分钟的写周报放不进 10:00–10:30，跳到站会之后；排在它后面的 20 分钟回邮件补进 10:00–10:20。「接下来」按实际排到的时间先后列出。
   - **长任务可以切开**，但每段（包括最后一段）至少 25 分钟。不够切成两个 25 分钟的任务就算短任务。
   - 进行中的任务不受这条限制，从现在接着做。
   - 「最短一段」在设置里改，设成 0 就回到从最早的空档起切开填满的老办法。
5. **还剩多少**：写了进度按进度算；没写但做过，按「预估 − 已经做掉的」算（包括前几天做掉的），至少留 5 分钟。
6. **父任务不重复算**：父任务下面挂着子任务、自己又没写时长，时间只算在子任务上。
7. **排到一天结束还没排完的**，进「排不下」，容量条变红。

### 容量条上的数字

口径和 Roam 上的 Nautilus Log 一致，两行：

| 数字 | 意思 |
|---|---|
| 已计划 | 没做完的待办一共还要多久 |
| 余量 | 排完已计划的以后还空着多少 |
| 超载 | 已计划的比可安排的时间多出多少。出现它就不显示余量 |
| 空档不足 | 总时间够，但没有一段连续的空档放得下某件任务，这么多分钟没排进去。只在没有超载时显示 |
| 剩余 n% | 余量 ÷ 全天可安排的时间。有一点余量就至少显示 1%，正好排满是 0% |
| 可安排 a / b | 从现在到收工还能安排的时间 / 全天扣掉事件以后能安排的时间 |
| 事件 a / b | 还没过去的事件时间 / 全天的事件时间。重叠的事件按并集算，同一分钟不重复算 |

🔥 标在「可安排」或「事件」前面，表示现在这一分钟流掉的是哪一笔。过去的日子可安排是 0，没做完的全算超载。攒够 10 件做完的任务以后，如果你的预估整体偏差超过 15%，第一行后面会多一句「按以往约 4h10m」。

## 螺旋怎么读

- 螺旋是一块 12 小时表盘，从一天的开始（最外圈）一路转到一天的结束（最里圈）。外面一圈数字是钟点。
- **颜色**：黄色是事件，蓝色是待办，红色是带重要标记的，灰色是做完的，青色是复习卡片。淡一些的蓝是已经做过的时段，实的蓝是接下来排的，正在做的那件从现在排起的一段会慢慢呼吸。这套颜色是按浅色主题配的。
- **切到别的 App 时动画暂停**：呼吸、闪动的 🔥、「现在」的光晕这些一直循环的动画，在 Obsidian 不在前台时停在当前那一帧，切回来接着播。只要有一个循环动画在播，整个窗口每一帧都要重画，后台一直开着很费电。
- **深灰色的指针**是现在，指针上的圆点往外散着一圈，中间写着当前时刻。
- **鼠标划过哪一段**，螺旋上方固定的那一行立刻用粗体显示这一段做的是什么，前面是起止时刻和时长，不用停下来等提示。同时这件事的几段和下面列表里的那一行一起亮起来，其余的线段淡下去；反过来停在列表的一行上也一样。
- **点任意一段**，跳到日记里那一行（日历事件则打开「日历」App）。
- **斜纹**是已经过去、没有任何记录的时间：既没有事件、做完的任务、做过的时段，也没有 Agent 会话和游戏记录。鼠标停在容量条下面第一行上，悬停提示里的「📝 已过去 9h20m · 有记录 6h05m（65%）· 没记录 3h15m」是同一件事的数字，还写着其中你记的多少、只有机器记的多少。它只是排程上的事实，不代表那段时间被浪费了。今天算到现在，过去的日子算整天。设置里的「显示没记录的时间」可以关。
- **还空着的时段**平时看不出来，鼠标划过去会亮一下，上方那一行显示「可用空档」和它几点到几点、多长；「现在」正落在里面的那一段写的是「当前可用」。过去的日子没有空档可用，不显示。
- **回放一整天**：点顶部的 ▷，6 秒里「现在」从这天的开头扫到结尾，待办跟着往后流、斜纹一路长出来，放完回到真实的现在。只是重画，不改日记。过去的日子也能放。
- **两个空心圆把手**是这一天实际的开始和结束。沿着螺旋拖动可以改（5 分钟一格），双击恢复默认。比如今天 10 点才起，把开始拖到 10:00，前面那段画成虚线，容量也跟着重算。
- **直接填时间**：点顶部的「☀️10:00–🌙--:--」，或者按 ⌃⌥T，在弹窗里写起床和收工的时刻（`10:30`、`1030`、`10点半` 都行；凌晨收工写 `2:30`，算到当天夜里）。两项都可以空着，空着的那项按原来的默认算，所以早上只填起床、收工等真收工了再填（或者 Telegram 发「睡了」）就行。「现在」一键填当前时刻，「默认」清空。

螺旋下面的列表分成几组：固定事件、接下来、排不下、⏸ 挂起、做过 · 已挪走、已完成。点任意一行跳到日记里对应的位置。

## ▶ 开始做：时间记录 + 番茄钟

写下预计时长，开始做，到点问你做完没有，做完的那一刻时间记录就写进日记。同一套东西既是计时，也是番茄钟。

```markdown
- TODO 写周报 15分钟
```

1. **开始**：在螺旋的「接下来」里点那一行的 ▶（鼠标移上去才显示），或者光标放在这一行按 **⌘⇧↵**。这一行变成 `DOING 14:05 写周报 15分钟`，同时开一轮 15 分钟的专注。打开了 Raycast 的话，也会开一段 15 分钟的 Raycast Focus。
2. **专注中**：容量条下面显示「⏱ 写周报 · 还剩 9m / 15m」，点「结束」可以提前收工。
3. **到点**：响一声，弹出系统对话框「做完了吗？」。Obsidian 在后台也看得到：
   - **做完了** → 这一行改成 `DONE 14:05-14:20 写周报 15分钟`，实际用时就记在日记里，和预估的 15 分钟放在一起。
   - **再来一轮** → 同样的时长再专注一轮，还是 DOING。
   - **先停下** → 改成 `PAUSED`，做过的时间留在计时里，下次剩余时间会相应变少。
   - 半小时没回答就不再等，任务保持 DOING。

专注多久：

- 条目上写了多久就专注多久：`10 min`、`15分钟`、`25m`、`1.5h` 都行，写在关键词后面或者句末都可以。
- 没写的按「默认任务时长」（15 分钟）。
- 写了进度（`2h 40%`）按还剩的时间。
- 想要固定的番茄钟，在设置「专注多久」里填 25，每轮都是 25 分钟。

**几条线并行**：专注进行中，再按 ⌘⇧↵ 或点 ▶ 开始另一件，它会加入这一轮，不另开新的：

- **每条线各自倒计时**，按各自写的时长算。容量条下面显示「⏱ 2 条线 · 写稿 还剩 12m · 回邮件 还剩 3m」。
- **哪条先到点就先单独问哪条**，别的线照常走；「再来一轮」只给这一条再加一轮。
- **点「结束」就整轮一起问**：先勾做完的，没勾的再问「再来一轮 / 先停下」。
- **Raycast 专注只开一段**，因为 Raycast 同一时间只能有一段专注；屏蔽干扰本来就是全局的，一段就够。这一段覆盖到最晚那条线到点；后来加进来的线超出了这一段，就结束重开一段，覆盖到它为止。
- **计时每条线各记各的**：三件一起做了 25 分钟，每件都记 25 分钟；一天的总时长按重叠合并，只算一次。

**在 Raycast 里点完成**：专注进行时，屏幕上有一个 Raycast 专注的悬浮小窗。插件只在这一轮开着 Raycast 专注时每 10 秒看一眼。小窗比计时早消失（连着两次、离到点还有半分钟以上、你人在电脑前），就当你在 Raycast 里点了完成，这一轮的几件都记成 DONE。开始 1 分钟内一直没看到小窗，这一轮就不再看。

其它细节：

- ⌘⇧↵ 在任何笔记里都能用。没有关键词的普通列表项会当成 TODO 开始；在编辑器里直接改，⌘Z 一步撤销。
- 已经是 DOING 的任务，开始时只开专注，不改那一行。最后写 DONE 时，开始时刻用 DOING 后面原来写的那个。
- 到点前自己把它改成 DONE 或 TODO（比如 ⌘/），这一轮就提前结束，不再弹窗，Raycast Focus 也一起结束。
- 命令「开始下一件」开始螺旋上排在最前面、还没开始的那件；「结束这一轮专注」等于点「结束」。
- Obsidian 在专注中途关掉了也没关系，这一轮存在设置里，下次打开时到点照样会问。
- Raycast Focus 用的是它的 Deeplink `raycast://focus/start?goal=…&duration=…`。屏蔽类别和模式（屏蔽 / 只允许）在设置里改；关掉「同时开 Raycast 专注」就只计时、只问。

点 ▶ 的时候，如果那一行刚被改过、对不上，插件不会动日记，只提示一下。

## 计时：实际做了多久

插件看着日记的变化自己记：

- 任务改成 DOING：开始一段计时。改回 TODO 或改成 DONE：这一段结束。中断再继续，就是好几段。
- 进行中的任务改了名字，计时跟着挪到新名字下面，算同一件事。
- 没做完的任务挪到明天（行尾带 `← 2026_09_30` 这种来源标记），前几天做掉的时间也算进去。
- Obsidian 关着的时候改成 DOING 的，下次打开时补上：写了开始时间按写的，没写从打开时算。
- 做完的任务，完成时刻按「DONE 后面手写的时间 > `**07:37**` 时间戳 > 插件看到它变成 DONE 的时刻」取。
- 没写时长、但记到了做的时段的任务，做完后时长按实际做的算。

计时记录保存在插件的 `data.json` 里，保留 45 天。这份是底稿，正本是日记里的 `⏱` 那一行，见下一节。

### ⏱ 那一行：写在日记里的实际时段

```
- DONE 🤖 给螺旋日程加悬停文字
	- ⏱ 09:59–10:18、10:33–10:34、20:10–20:40 · 共 50m · 48k tok · [Claude](claude://resume?session=…)
```

任务下面以 `⏱` 开头的子项是这件事实际做的时段。它不是任务也不是事件，排程不看它；螺旋、列表、当日复盘和预估复盘用它算实际用时。

- **谁来写**：Agent Deck 自动记日记管着的行，由它在搁置、做完时写，后面是这一行名下的会话当天用掉的 token（产出 + 读入，不算缓存命中）和是哪个 Agent 记的；只有一个 Claude 会话时，Claude 这两个字是链接，点了回到那个会话。打开设置里的「实际时段写回日记」之后，你手动做的任务也写：不再是 DOING（做完、暂停、改回 TODO）时写一行，写法一样，后面没有 Agent 的名字。默认关着，因为它会多改日记。
- **以它为准**：任务没在做的时候，实际用时按这一行算。觉得机器记得不对，直接在这一行改，螺旋跟着变。过了 45 天、或者换了一台电脑，插件自己的计时记录没有了，靠的也是它，所以「复盘看最近几天」可以设到 365。
- **三种情况不按它**：正在做的任务（还在往下记，这一行是上次停下时写的）；段数太多只写了最后 8 段、开头带 `…` 的（计时记录还在就用计时记录）；行尾带 `← 2026_09_30` 的（从别的日子挪过来的，它带着的 `⏱` 说的是原来那天）。
- **怎么写都认**：时段之间用顿号、逗号、分号都行，起止之间用 `–` `-` `~` `到` 都行，合计写 `共 57m` 或 `共 1小时21分` 都行。合计写了就按合计算，因为挨得近的几段（隔不到 10 分钟）写的时候并成了一段，照段落加会把中间的空隙也算进去。

### 任务行下面的进度条

```
- DOING 14:05 写周报 2/3
  [#############-------] 67%
- DOING 给螺旋日程加悬停文字
  [      ###           ] 监听 Claude · 在跑 · 改 main.js · 48k tok
```

编辑器里 `DOING`（或 `[/]`）的那一行下面多一行等宽字符。它是画上去的，不在笔记正文里，光标进不去，也不会被同步、导出带走。数从哪来，按这个顺序：

1. **你写在这一行里的进度**：`60%`、`2/3`、`三分之一`、`一半`（和排程读的是同一种写法，数字前面要有空格）。改了数，`#` 一格一格长到新的位置。
2. **监听对上的 Agent 会话**：它自己列了待办（Claude 的待办清单、Codex 的 plan），按做完几步算，写成 `3/7 步`。没列待办就没有百分比可看，三个 `#` 来回走表示它在跑。
3. **预计时长**：这一行写了时长、关键词后面又有开始时刻，按已经做了多久算，`14m / 30m`，超了写超多少。

三样都没有的 `DOING` 行不显示。

**监听**：对上了会话，后面写它眼下的状态。`在跑` = 你刚发了话或者它在调工具，5 分钟内有动静；`等你回复` = 这一轮答完了；`等你点允许 · Bash` = 停在权限提示上（要装下面「等权限的钩子」）；`20m 没动静` = 说是在跑但很久没写日志。再后面是它最近一步在干什么（跑的命令的说明、改的文件名）和这个会话最近 7 天用掉的 token。每 10 秒看一眼会话日志有没有新内容。

**状态跟着会话走**：对上了会话的那一行，关键词跟着会话切（`TOREVIEW` 等你看、`NEEDOK` 等你点允许、`ERRORED` 报错停了、`HITLIMIT` 撞了限额、`QUEUED` 排进了续跑队列，又动起来回 `DOING`），这件事由 Agent Deck 做；螺旋照样认这几个关键词（算暂停：计时停、照常排、⌘/ 一按回 DOING），进度条照画，上面写着会话眼下的状态（「等你点允许 · Bash」「报错停了 · …」「撞限额 · 13:00 恢复」「排队续跑 · 13:00」）。

**等批准、报错时发通知**：最近一天的会话（不只挂在日记里的）刚停到「允许吗？」上，或者这一轮以报错结束，弹一条系统通知（标题「✋ 等你批准」/「⚠️ 会话报错停了」，正文是任务名和要用的工具 / 报错的头一句），点一下跳到日记里那一行，没挂在日记里的打开那个会话。Obsidian 在后台时带一声提示音，在前面时只响状态音。刚打开 Obsidian 的第一轮不弹，免得把早就停着的一起弹出来。设置里「会话要你批准或报错时发通知」可以关。

**等权限的钩子**：Claude Code 弹「允许吗？」的时候不写会话日志，光看日志只能等 5 分钟没动静才认出来。装一个 Claude Code 钩子就能当场认出：弹框时（`PermissionRequest`，以及 `Notification` 的 `permission_prompt`）往 `~/.local/state/agent-wait/<会话号>.json` 写一个记号（会话号、时刻、哪个工具、claude 进程号），你发话、这一轮结束、会话关掉时（`UserPromptSubmit` / `Stop` / `SessionEnd`）删掉。螺旋日程每 10 秒读一次这个目录，有记号的会话算「等你点允许」，进度条当场写「等你点允许」，弹一条通知，和答完一轮一样敲两下。你点了允许就算放行：工具跑完日志里有了新动静，或者 claude 进程底下在记号之后起了 Bash 命令的 shell（长命令还在跑、日志里还没动静）。本机的钩子脚本是 `~/.local/bin/agent-wait`（`perm` / `clear` 两个子命令），没装钩子的照旧按「好几分钟没动静」认。批准后跑很久的不是 Bash 的工具（MCP 调用之类），跑完之前还会显示成在等批准。

**会话怎么对上**：Agent Deck 自动记日记记下的那一行，直接用；没有的话看重名（会话标题和这一行的字一样，或者一个包含另一个），或者你在会话里发的话带着这一行的字。所以把一行任务原样贴给 Claude / Codex 当第一句话，它下面就会开始显示那个会话的状态。几个会话都对得上，取最近在动的。只在今天有动静的会话里找。

**手动绑定**：对不上、或者对错了，光标放在这一行任务上，跑命令「把这一行绑定到一个 Agent 会话…」，从最近三天有动静的会话里选一个（能搜标题、你发的第一句话、目录）。它在任务下面写一行：

```
- DOING 20:55 搭建体重秤数据同步
	- 🔗 [Claude：小米体重秤数据自动化推送](claude://resume?session=…)
```

绑定就是这一行字，写在日记正文里：这一块挪到哪、发到哪天、任务的字改了都还认，换一台电脑也在。绑了以后这一行只听它，进度条前面写的是「绑定」不是「监听」，那个会话今天没动静也照样认。Claude 的 `🔗` 是链接，点了在 Claude 桌面版里打开那个会话；别的 Agent 没有这种链接，会话号写在反引号里。想解除，把这一行删掉，或者跑「解除这一行和 Agent 会话的绑定」。

「块去向」插件把一块发给 Claude CLI 时会自己写上这一行。

**归档了**：对上的会话在 Claude 桌面 app、Codex 或 DeepSeek Harness 里归档了，进度条走到 100%、写「已归档」。这一行记成 `DONE`、`⏱` 行和 `🔗` 的收尾，由 Agent Deck 做。终端里开的 Claude Code 会话没有归档这回事，要在 Claude 桌面 app 里归档它才算。

对上了 Claude 会话的进度条可以双击：在 Claude 桌面版里打开那个会话（`claude://resume` 深链接，桌面版里还没有的会先导入；子代理的打开派它的那个会话）。任务下面的 `💬` 结论行、`🤖 子代理` 行双击也一样，打开同一件任务的 `🔗` 绑着的会话。

设置里的「任务行下面的进度条」可以关。

### 💬、subagent、子会话

这几样写进日记的事现在都由 Agent Deck 做，螺旋只负责显示：

- **`💬` 那一行**：任务下面有 `🔗` 的，会话每答完一轮，Agent Deck 把最后那条回复压成一行 `- 💬 …` 写在任务下面。螺旋把这一行放淡，排程、状态音效都跳过它，双击打开 `🔗` 绑着的那个会话。
- **subagent 和 side chat**：对上的是 Claude Code 会话时，它派出去的 subagent、你在 Claude 桌面版里给它开的 side chat，进度条末尾多一截 `🤖 2 跑 1 完`，下面一个一行（描述、在跑还是跑完了、最近一步、token；side chat 写开着、开了多久）。subagent 的日志在会话目录的 `subagents/` 下；side chat 不落盘，只能看到桌面版为它起的那个 claude 进程。
- **会话里开出来的会话**：在 Claude 桌面版里，绑着的会话又开出新会话，Agent Deck 把它写成这件任务的子块、带上它自己的 `🔗`；螺旋给每个子块各画一条进度。

### 状态栏

右下角常驻一格，不用把螺旋开在眼前：

- **在做事**：`▶ 12:34 · 写周报 · 2 件`，最近开始的那件做了多久、一共几件在做。连着做了 45 分钟，计时变红；开了 2 小时，变成「⚠ 检查计时」。这两样都只是提示，不替你停，阈值在设置里改，填 0 关掉。
- **只选了方向的一轮专注**：`⏱ 12:34 · 专注`，正计时。
- **没在做**：今天的容量，`🌀 已计划 2h10m · 余量 45m · 剩余 23%`，超载或空档不足时变橙。
- **点它**：单击打开螺旋日程，⌥ 单击到日记里正在做的那一行，⇧ 单击在旁边分栏打开今天的日记。

### 界面音效

全是现合成的短音，不带声音文件。在编辑器里改的（`⌘/`、点关键词、手敲）当场就响，不等笔记写盘。Obsidian 不在最前面时不响；设置里的「界面音效」一个开关全关。提醒用的系统提示音另外设。

**点一下**：螺旋上的任何一段（事件、任务、Agent 的细线、斜纹、空档），列表里的任何一行（接下来、已完成、人机协作、当日复盘…），⌃⌥V 面板里的行和按钮，都是一声轻的「嗒」。

**任务状态变了**：库里任何一篇笔记，只要某一行的关键词变了就响一声，不管是谁改的：TODOseq 里点关键词、`⌘/` 快切、看板上拖、手敲都算。声音分两种情绪：

| 状态 | 声音 | 情绪 |
|---|---|---|
| `TODO` | 三角波，干净的一声 | 往前走：正弦和三角波，音往上；最常听的 `DONE` 不往高处走，落在主音上，低一点、软一点 |
| `DOING` | 往上跳五度 | |
| `DONE` | 两个音轻轻往上，落在主音上，起音慢一点 | |
| `PAUSED` | 轻轻落一步 | 停下来、没成：音往下落，越往后越低，波形也越糙 |
| `WAITING` | 同一个音敲两下，悬着 | |
| `SUSPENDED` | 往下落四度 | |
| `CANCELLED` | 方波，短促地落下去 | |
| `FAILED` | 锯齿波，最低最沉 | |

复选框也认：`[ ]` 是 TODO，`[/]` 是 DOING，`[x]` 是 DONE，`[-]` 是 CANCELLED。关键词整个去掉是一声短的。

几种情况不响：新写一行、删一行、只是挪了位置或者改了字；一下子变了三行以上（那是同步或者批量整理，不是你在点）；机器自己整理日记的那几秒；一篇笔记打开以后的头一次保存之前（要先记下它原来的样子才有得比）。

另外，回放的开始和结束、把会话整理进日记，各有自己的一声；挂在大纲上的会话刚答完一轮、轮到你了，敲两下（和 `WAITING` 同一个音）。

## 硬规则：暂停

只管今天的日记。每次因为这些规则把任务改成 PAUSED，都会发一条系统通知，点一下跳到那一行。

- **同时最多 3 件 DOING**：开始第 4 件时，最早开始的那件改成 PAUSED。正在专注里的几件排到最后才会被暂停。交给 Agent 在做的不算数，也不会被暂停：Agent Deck 自动记日记记下的、下面挂着 `🔗` 的、自动对上了某个会话的任务，连同它所在的整块（顶格那一项和它下面的子项）。比如把一整块资料整理发给了 Claude，块里五六行同时是 DOING，你自己手上的事照样还能开三件。
- **3 小时没动就暂停**：一件 DOING 的这一行和它下面的子项 3 小时都没改过，也不在专注里，就改成 PAUSED。Agent Deck 自动记日记记下的行不管，吃饭 / 锻炼时也不动它们。
- **吃饭 / 锻炼**：新写一条只有「吃饭」或「锻炼」的条目，可以带时间、时长、标点、表情，但不能有别的汉字和英文字母，比如 `**12:03** 吃饭`、`🍚 吃饭`，从 Telegram 发过来的也算。这时所有 DOING 改成 PAUSED；正在专注的话，专注也停掉，并记下还剩多久。`TODO 吃饭`、`和小李吃饭`、`18:00-19:00 吃饭`（还没到点的计划）不算。
- **回来了**：点螺旋上的「回来了」，或者按 ⌃⌥B，弹窗问「要把这几件切回 DOING 吗？」。点「切回来」，那几件改回 DOING，没专注完的那轮接着开。吃完直接自己开始做某件事也行，这次就不再问。

上限、小时数、吃饭 / 锻炼的词，都在设置里改；填 0 就关掉对应的规则。

`PAUSED` 和 `SUSPENDED` 的区别：PAUSED 只是停一下，照常排进螺旋，⌘/ 一按就接着做；SUSPENDED（还有 WAITING）是暂时搁置、短期不推，不排、不占容量，列在「💤 搁置」里。TODOseq 里 PAUSED 归在「未开始」，SUSPENDED 归在「等待」。

## 🎯 主线

一天里最要紧的一到三件事。在任务上写 `[#A]`（或者简写 `TODO a 写简历`、`todo a写简历`），它所在的那一整块（顶格那一项连同子项）就是今天的一块主线；`todos：` 母块下面没写关键词的 `[#A]` 子项、交给 AI 的 `TODO4AI [#A]` 也算；一天最多 3 块，按日记里的先后取，多出来的不算（配套的日记整理会把它们降成 `[#B]`）。

- 列表最上面「🎯 主线」一节；排程时排在 DOING 后面、别的待办前面；螺旋上用绿色画。
- 容量条下面一行 `🎯 ●◐○ 主线 1/3 · 下一件`：● 做完、◐ 在做、○ 没开始、✕ 没做成（`FAILED`），一件 A 级任务一个。完成率按 A 级任务算：取消的不算进去，没做成的算进总数、不算做完，也不会再被当成「下一件」。
- 列表「🎯 主线」一节里，排程不管的那几件照样列出来：`TODO4AI [#A]` 写「交给 AI」，`FAILED [#A]` 写「没做成」。
- 状态栏没在计时时显示下一件主线。
- 到设置里的提醒时刻（默认 15:00、22:00）主线还没做完、手上也没在做主线，提醒一次；还没定主线的，提醒定一个。
- 过了日期分界，把前一天的完成率写进那篇日记的属性 `mainline: 2/3`、`mainline-rate: 67`。

**先定目标再开始**：主线任务（A 级那一行）一变成 DOING，下面还没写目标的，弹一个框问「做到什么程度算完成」。写一句能验收的话，按回车或「定下来，开始」，记成这件任务下面的第一行：

```markdown
- DOING 14:05 [#A] 写简历
	- 🎯 目标：简历 PDF 投出 3 份，项目页的二维码能扫开
```

点「先不开始」或者关掉框，这一行改回 TODO：主线不定目标不开始。每分钟也会看一遍，这条规则加上之前就在做的主线一样会问。交给 Agent 在做的不问。`🎯 目标：` 这一行和 `🔗`、`⏱` 一样是记号行：不是任务也不是事件（里面写了时刻也不算），状态音效不响；块去向把这一块发给 Agent 时照常带上，正好当验收标准。

**能拖的进度条**：日记里每个主线块第一行（顶格那一项）下面一条细进度条，不放到子块后面；块里每件 A 级任务一条（只有一件时不写名字）。拖到几就是百分之几（每格 5%），松手把进度写进那一行：已经写了 `40%`、`1/3`、`三分之一`、`一半` 的换掉，没写的加在行尾（块 ID、`%%` 注释、`← 日期` 这些尾巴前面）。做完了的那件显示「✓ 做完了」。设置里关掉主线，进度条也不画。

## 🗓 macOS 小组件

四个小组件，可以放在桌面上，也可以放进通知中心的侧栏：

- **今天的主线**（小号、中号）：做到第几件、在做哪件 / 下一件和它的目标（没写目标标成橙色）；中号左边是进度环和近 7 天每天的完成率，右边逐件列出。
- **在做**（小号、中号）：今天日记里 `DOING` 的几件，各做了多久（计时自己走，不用刷新）；主线的带一个靶心。
- **待办**（小号、中号、大号）：全库还没做完的条目，写了 `TODO` / `LATER` 的列表项和 Markdown 任务框 `- [ ]` 都算（代码块里的不算），最近改过的笔记排前面，右上角是一共几条；中号、大号在右边写出自哪篇笔记。点圆圈在那篇笔记里勾掉：任务框打勾，`TODO` / `LATER` 改成 `DONE`。
- **计划甘特图**（大号、特大号）：从这周一起画 5 周。数据来自设置里的「计划笔记」（默认叫 `上班计划.md`，没有就照模板新建一篇）：列表项里写了 `🛫 开始`、`⏳ 计划`、`📅 截止` 日期的各画一条（Tasks 插件的写法），只写一个日期的画成那一天的一个菱形；上面最近的标题、或者没写日期的顶格列表项是分组，一组一种颜色；做完的（`DONE`、`[x]`、`✅ 日期`）画淡，过了截止还没做完的画成红色；没写日期的子项不画，细节写在那里正好。

```markdown
- 求职
	- [ ] 简历改造 🛫 2026-10-26 📅 2026-11-01
		- 项目汇总到作品页，二维码代替一串链接
	- [ ] 投递第一批 📅 2026-11-20
- 家教
	- [ ] 上课和课后反馈 🛫 2026-10-26 📅 2026-11-29
```

主线和在做的有个 ✕ 表示没做成（`FAILED`）。每个小组件右上角有一个刷新按钮：点了叫螺旋日程马上重算一遍；Obsidian 没开着时只是重读一下现有的数据。

**双向**：每一行前面有个圆圈，点一下在日记（甘特图是计划笔记）里记成做完，做完的再点撤回：主线和在做的那一行改成 `DONE 14:05-15:30 …`（还没开始的写成 `DONE 15:30`），撤回改回 `TODO`、把 DONE 后面的时刻一起去掉；甘特图那一行勾上勾选框、记上 `✅ 日期`，撤回反过来。小组件当场换成新的样子，Obsidian 开着时一两秒内改好日记；没开着的，先存在 `inbox/` 里，下次打开再改。点的是前一天的画面（过了日期分界小组件还没刷新）就不改。

点名字跳回 Obsidian 里那一行（主线、在做跳日记，甘特图跳计划笔记，待办跳它所在的笔记），点别处打开今天的日记。小组件上的链接点下去先交给小组件 App（WidgetKit 就是这么送的），它再转给 Obsidian，用的是插件注册的 `obsidian://nautilus-open?note=…&kind=…&text=…`。

**怎么找到那一行**：主线和在做里你自己的那几行，插件会在行尾补一个块 ID（`^nw-` 开头的六位），链接带着它，点的时候按块 ID 找，这一行改了字、挪了位置也找得到。不补的有三种：光标正停在那一行（你在打字，行尾不能突然多出一截）、Agent Deck 记的行和带 🤖 的行（Agent Deck 按整行的字认自己的行，尾巴变了它会认不出来）。这些、以及甘特图和待办，链接里写的是那一件的文字（待办还带行号），点的时候现找它在第几行，所以上面多写几行，小组件不用跟着刷新。

**装上**：小组件是一个单独的 macOS App，源码在插件仓库的 `widgets/`。要有 Xcode、XcodeGen（`brew install xcodegen`）和一张 Apple Development 证书（Xcode → 设置 → Accounts 登录 Apple ID 就有，免费账号也行），然后在 `widgets/` 里跑 `./build.sh`，它会编译、签名、装进 `~/Applications/NautilusWidgets.app`。再到螺旋日程的设置里打开「给小组件导出数据」、填好「计划笔记」，右键桌面 →「编辑小组件」→ 搜「螺旋日程」，把四个小组件拖出来；通知中心的侧栏是点右上角的时间、最下面「编辑小组件」。

**怎么更新**：插件跟着主线的计算每分钟算一次、今天的日记改了也算一次，主线、在做、待办或计划的内容真变了（改了状态、改了字、加减了一件）才把数据写进 `~/Library/Application Support/Nautilus Spiral/widgets.json`，再用 `nautilus-widgets://reload` 叫那个 App 在后台刷新小组件（它刷新完两秒就退出，不常驻）。系统给小组件的刷新次数有限，所以小组件自己不轮询，只在中午和半夜各换一次画面（主线算不算过期、甘特图的「今天」往后挪一格）。小组件跑在沙盒里，只给了读写这一个文件夹的权限（要往 `inbox/` 里放点了什么）。Obsidian 没开着时主线停在最后一次的样子，小组件上会写「主线停在某天」。

双击 `NautilusWidgets.app` 会开一个窗口，显示四个小组件现在的样子；`NautilusWidgets.app/Contents/MacOS/NautilusWidgets --render <目录>` 把各个尺寸画成 PNG（浅色、深色各一张）。

## 开一轮专注：只选大方向

命令「开一轮专注（选一个大方向）」（⌃⌥F）弹一个框，只选这一轮的**大方向**和时长（25 / 50 / 90 分钟），不列一条条任务。方向在设置里写，最多 4 个，默认是「🧩 工具、🎬 创作、💼 工作」，改成你自己的。数字键 1–4 选方向，← → 换时长，↵ 开始。

选了方向的这一轮只计时、开 Raycast Focus，到点问「再来一轮 / 换个方向 / 收工」，不改日记里的任何一行。具体做了哪几件、各用了多久，交给 Agent Deck 的自动记日记。

已经在专注、或者在吃饭 / 锻炼时不弹。

## 🤖 Agent 会话写进日记：交给 Agent Deck

不装 Agent Deck 的话，螺旋日程就是一个任务管理插件，这一节可以跳过；想把 Agent 做的事记进日记，再装 Agent Deck 一起用。

你在日记里写任务，是预计；Agent 的会话日志是它自己会写的实际记录。把这份被动记录写回日记（会话在动的那一行改成 `DOING`、停了改成 `PAUSED` 并写下 `⏱` 实际时段、归档了记成 `DONE`、回复里要你做的事另记 `TODO 🤖 …`），现在只由 [Agent Deck](https://github.com/MatsuriMW/obsidian-agent-deck) 做。螺旋日程以前也有一套（「自动记日记」「会话停下来时改任务的状态」「会话的结论写回任务下面」「状态栏的 Agent 汇总」「每周方向回顾」，以及 ⌃⌥L、⌃⌥A 两个快捷键），和 Agent Deck 重了，已经拿掉。

螺旋这边照样读会话日志，负责显示：人机协作的时长和 token、螺旋内圈的细线、任务行下面的进度条、会话等你批准或报错时的通知。Agent Deck 记下的行，螺旋也认得（读它记的会话和行的对应关系）：用时按会话真正在动的时段算，不走「改成 DOING 就开始计时」那一套，也不受 DOING 上限、超时暂停和吃饭暂停管。

## 🤖 做这件事时 Agent 在干什么

一件任务做过的那几段时间里，有哪些 Agent 会话在干活，就在列表那一行后面显示 🤖2，螺旋上悬停那一段也能看到。

- **只看时间会把同时开着的无关会话也算进来**，所以还会看内容：会话标题，或者你在会话里发的话，出现了任务名里的词，就算「看起来相关」。🤖 后面的数字是相关的个数。只有时间重叠、看不出相关的，🤖 是淡的。
- **点 🤖** 打开列表，按「看起来相关」和「同一时段的其它会话」分开，显示每个会话的标题、你发的第一句话、工作目录、和这件任务重叠多久、消耗多少 token（产出 + 读入）。
- **回到那个会话**：Claude 桌面版里开的会话，「在 Claude 里打开」用 `claude://resume?session=…` 直接打开；终端里开的会话，「在终端里继续」在它的工作目录里运行 `claude --resume …`；Codex 的会话同样有「在终端里继续」，运行的是 `codex resume …`；也可以复制命令自己跑。WorkBuddy 的会话只列出来，要回它自己的窗口里找。

数据来自人机协作那一块读的本地会话日志，几条线并行时，同一个会话可能同时挂在几件任务上。

## 📋 当日复盘

列表里的「📋 今日复盘」回答一个问题：今天哪几件事和预计的不一样，差了多少。默认收着，标题上带结论（已完成几件、偏差多少），点开是逐件的对照，按日记里的顺序列。翻到过去的日子看的是那一天的。

| 状态 | 是什么情况 |
|---|---|
| 已对比 | 做完了，也记到了实际用时。这一行显示偏差：实际 − 预计，`+12m` 是多用了 |
| 未计时 | 做完了，但没记到实际用时。写的是「未计时」，不写 0 |
| 进行中 | 没做完，正在做 |
| 已暂停 | 没做完，没在做，之前做过一阵 |
| 未开始 | 还没有用时 |
| 未预估 | 这一行从来没进过计划：自动记的 🤖 行，或者 `DONE 18:02 写稿 2h` 这种直接记做了多久的。只列实际，不进对比 |

- 汇总只算「已对比」的那几件：预计一共多少、实际一共多少、偏差多少。两边是同一批任务，在做的、停着的不影响偏差。
- 预计按行上写的时长，没写的按默认任务时长，因为排程也是按它排的。
- 固定事件不算（时间段是约定，不是预估），带子任务的大项和复习卡片也不算。
- 多用了的偏差用橙色提一下，少用的不特别标：省下时间不算功，多花时间也不算过。
- Telegram 发「睡了」的回执和 ⌃⌥V 里也带这一行汇总。

前五种状态和汇总的算法照 Nautilus Log 的每日回顾；「未预估」是这里加的，因为机器记的行没有预估，拿默认的 15 分钟去比没有意义。

## 📏 预估 vs 实际

列表底部的「📏 预估 vs 实际 · 近 30 天」，看你写的时长长期来看准不准：

- 整体：做完的几件里，预估一共多少、实际一共多少、整体多用或少用了百分之几，估短、估长、差不多（±20% 以内）的各几件，一件一般是预估的几倍。
- 按标签 / 链接分：行里有 `#口播`、`[[某个项目]]` 的，按它们分组，列出偏差最大的几组，比如「×1.6 #口播 5 件」。
- 估得最短的几件：点一下跳到那天日记里的那一行。
- 容量条上的校准：攒够 10 件以后，如果整体偏差超过 15%，第一行后面会多一句「按以往约 4h10m」，也就是按你的习惯，这些待办实际大概要多久。

只算这样的任务：做完了，写了预估时长，也记到了实际用时。实际用时来自 `DONE 开始-结束`，或者 DOING 时插件记下的那几段。用 ▶ / ⌘⇧↵ 开始、回答「做完了」的任务，天然满足这几条。`DONE 18:02 写稿 2h` 这种只写了做了多久的不算，因为那个 2h 是实际，不是预估。计时记录保留 45 天，所以最多看 45 天。

## 提醒怎么发

- **不用你回答的**（自动暂停、欢迎回来、专注到点）：设置了 Discord 频道就发到 Discord，见下一节；没设就在本机弹一条通知，并响一声提示音。几秒之内连着来的同一类提醒会折成一条。
- **要你回答的**（专注到点问做完了吗）：弹一个系统对话框，Obsidian 在后台也会到最前面。
- **提示音**：设置里的「本机提醒的提示音」填系统声音的名字（Pop、Glass、Ping、Tink、Submarine……）或者一个声音文件的路径，空着不响。

设置里的「到点怎么问」还有一个试验选项「带按钮的系统通知」：在本机编译一个很小的通知 App，把按钮放到通知上。它要系统允许这个 App 发通知，在有的 macOS 版本上系统不认本机签名的 App，会一直发不出来，所以默认不开。

## 提醒发到 Discord

如果你把 Discord 当成各种机器提醒的汇总处，可以让螺旋日程的提醒也进去。设置里的「提醒发到 Discord 的哪个频道」填一个频道名，插件就调本机的 `notify-discord <频道> <内容>` 脚本发过去（Webhook 地址由那个脚本自己管，插件不碰）。空着就不发。

- **不用你回答的提醒**（超过上限或太久没动被暂停、吃饭计时暂停、欢迎回来、专注到点）发到 Discord。发出去了，就不在本机再弹一遍。
- **要你点按钮的**（做完了吗、要不要切回 DOING）照旧在本机弹，Discord 里只留一行记录。Webhook 只能发、收不到你点了什么，所以按钮没法放到 Discord 里。
- 发过去的内容里有任务名，也就是日记里那一行的文字。

## 📅 Google 日历

除了 macOS「日历」，也可以直接读 Google 日历，走的是 Google Calendar API。两个可以同时开，同一件事两边都有（比如 Google 账号也加进了 macOS「日历」）只留一份。不在 Mac 上、或者不想把 Google 账号加进系统的，用这个。

要用你自己的 OAuth 客户端，插件不带公共的密钥。配一次，大概五分钟：

1. 打开 [Google Cloud Console](https://console.cloud.google.com/)，新建一个项目（名字随便）。
2. 「API 和服务 → 库」里搜 Google Calendar API，点「启用」。
3. 「API 和服务 → OAuth 权限请求页面」：用户类型选「外部」，填应用名和你的邮箱；在「测试用户」里加上你自己的 Google 账号。
4. 「API 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID」，应用类型选**桌面应用**。建好以后会给你一个客户端 ID 和一个客户端密钥。
5. 回到 Obsidian：设置 → Nautilus Spiral → Google 日历，打开「读 Google 日历」，填客户端 ID 和客户端密钥，点「连接」。浏览器会打开 Google 的登录页，选账号、同意「查看日历」，页面显示「连上了」就可以关掉。

之后的行为和 macOS 日历一样：

- 只读，申请的权限只有 `calendar.readonly`，不改日历，也不写进日记。
- 只读你在 Google 日历界面左边勾着显示的那些日历；「不读这些日历」对它也管用，「列出日历」能看到名字。
- 线段和列表用那个日历自己的颜色，列表里带 📅；点一下在浏览器里打开这件事。
- 全天事件不占时间，列在下面「固定事件」里；已取消的、你拒绝了的邀请不算；日记里已经手写了同一件事的不重复。
- 每两分钟重读一次；命令「重新读取日历（macOS 日历 / Google 日历）」可以马上重读。
- 授权过期或者被你在 Google 账号里撤销了，容量条下面会提示重新连接。应用停在「测试」状态时，Google 会让授权每 7 天失效一次，嫌烦就在权限请求页面把应用「发布」。
- 「断开」会删掉存着的授权。客户端密钥和授权都存在系统钥匙串里（Obsidian 的密钥存储），不在插件的 `data.json` 里，不会跟着库同步出去。

## 📅 macOS 日历

设置里打开「读 macOS 日历」后，系统「日历」App 里的事件（iCloud、Exchange、Google 帐号、订阅的日历，只要日历 App 里看得到就行）会当固定事件排进螺旋：

- 只读，不改日历，也不写进日记。
- 线段和列表用那个日历自己的颜色，列表里带 📅；点一下打开「日历」App。
- 全天事件不占时间，列在下面「固定事件」里。读不到日历时，容量条下面会有一行「📅」说明原因。
- 已取消的事件、自己拒绝了的邀请不算；同一件事出现在好几个日历里（比如两份节假日日历）只算一次；日记里已经手写了同一件事的也不重复。
- 「不读这些日历」可以排除不想排进来的日历，设置里点「列出」能看到本机所有日历的名字。
- 每两分钟重读一次；命令「重新读取日历（macOS 日历 / Google 日历）」可以马上重读。
- 任务提醒插件、Telegram 的 `?` 也会把日历事件算进容量。日历事件快开始时，任务提醒不再另发通知，「日历」App 自己会提醒。

读日历用的是系统的 EventKit：第一次打开时，插件在本机把一个很小的 Swift 读取程序编译到 `~/Library/Caches/nautilus-spiral/`（需要 Xcode 命令行工具，没有的话运行 `xcode-select --install`），然后系统会问「“Obsidian”想要访问你的日历」，选允许。之后在「系统设置 → 隐私与安全性 → 日历」里可以随时关掉。

## 翻看其它日子

- 顶部 `‹` `›` 前后翻，「今天」回到今天。
- 在日历或文件列表里打开任何一篇日记，螺旋跟着切到那一天。
- 过去的日子：显示那天实际做了什么、哪些没做完。以后的日子：从一早开始预排。

## 可选模块

这几个模块都可以在设置里关掉：

- **🤖 人机协作**：读 Agent 留在本机的会话日志，在容量条下面的「🤖」那一行显示当天协作了多久、消耗多少 token（产出 + 读入，悬停看产出、读入、缓存命中各多少，几个 Agent 各用了多少，各个大方向各花了多久），螺旋内圈用细线画出 Agent 在干活的时段，列表底部按项目分开并给出近 7 天的柱状图；点某个项目那一行，列出它这天的几个会话，能直接回到那个会话。支持四个，在设置的「🤖 主力 Agent 和要追踪的 Agent」里选：
  - **Claude**（`~/.claude/projects`）：Claude Code，以及 Claude 桌面版里的 Code 会话。
  - **Codex**（`~/.codex/sessions`）：桌面版和 `codex` 命令行都算。token 取的是 Codex 自己记的累计用量，和它界面上的数对得上；会话标题读 `session_index.jsonl`；归档的会话接着读 `archived_sessions`；自动审查这类子线程的时间和 token 记在主会话名下，不单算一个会话。
  - **WorkBuddy**（`~/.workbuddy/projects`）：桌面版。
  - **DeepSeek Harness**（DSH 的本机 `dsh-token-usage-stats` 接口 + `~/.dsh/storages/workspace.json`）：桌面版。token 走 DSH 自己算好的跨会话统计（端口自动找，也可以在设置里写死），归档状态读 workspace.json。

  **主力 Agent 全量追踪，其余只追踪今天的**：主力读它全部的会话历史；别的开着的 Agent 只读今天有动静的会话文件、只算今天的动静，今天的时长、token、螺旋内圈都照常，以前的会话不翻。前几天已经汇总进来的照样留着。主力总是开着，换主力以后最近两周的日志会重读一遍。

  一个 Agent 一圈、一种颜色，Claude 橙、Codex 淡蓝、WorkBuddy 青绿、DeepSeek 蓝，列表里的 token 数和柱状图也按这个颜色分。关掉的那个不再读，已经汇总进来的历史留着但不显示，重新打开就回来。汇总另存在插件目录的 `ai-usage.json`，Claude Code 清掉旧日志后历史还在。
- **🃏 复习卡片**：第二大脑的每日回顾会在日记里记「DONE 14:10-14:12 复习卡片 23 张（…）」（每张按 5 秒算），螺旋上这一段画成青色，列表里那一行左边也是青色，当天一共复习了几张写在容量条第一行的悬停提示里。
- **🎮 游戏时间**：每分钟看一眼有没有在玩（进程关键词和「在最前面才算」的 App 都可以设置），螺旋最里一圈画紫线，记在 `game-log.json`。只在 Obsidian 开着时记录。

## 和 Telegram Companion 联动

[Telegram Companion](https://github.com/MatsuriMW/telegram-companion) 是同一个作者的另一个插件：手机上发给 Telegram 机器人的话直接进当天日记，想聊的时候它先读你近一周的日记再开口。两个插件是一起长出来的，放在一起时手机就成了螺旋日程的遥控器：

| 你在 Telegram 里 | 螺旋日程这边 |
|---|---|
| 发 `?` 或 `/now` | 回一张今天的螺旋图，加上正在做什么、接下来几件、哪些排不下 |
| 发「起了」「睡了」 | 把这一天实际的开始和结束设成你说话的时刻，顺便算出昨晚几点睡、睡了多久 |
| 发「去吃饭了」「去锻炼了」「午睡」 | 正在做的事暂停计时；回来说「吃完了」「练完了」「醒了」再切回去 |
| 发 `done 写稿 2h`、`doing 写稿` | 直接改今天日记里对应的那条任务并补上时间（这一条还要装 Done To Top） |
| 周日晚上 | 收到一条「本周方向」回顾 |
| 和它聊天 | 它读得到今天做完几件、还剩多少、这几天几点收工，而不只是日记里的字 |

**怎么配**：先按 Telegram Companion 自己的上手指南把机器人配好（建一个机器人、填令牌、给它发一条消息让它认得你）。之后两个插件都启用就行，螺旋日程这边什么都不用填：机器人的令牌和你的聊天号只存在 Telegram Companion 的设置里，螺旋日程要发消息时去读它的。

再加一个[任务提醒](https://github.com/MatsuriMW/Obsidian-Plugins/tree/main/nautilus-notify)的话，定时的日程图、拖了好几天的待办（带按钮）也会推到同一个机器人。

Telegram Companion 只在桌面端跑，电脑上的 Obsidian 得开着，手机上发的消息才有人接。

## 和其它插件一起用

- **任务提醒**（[`nautilus-notify`](https://github.com/MatsuriMW/Obsidian-Plugins/tree/main/nautilus-notify)）：用螺旋日程算出的排程发 macOS 通知：事件快开始了、钉住的待办过点了、DOING 做太久了、今天排不下了、下一件该做什么，还有早上的今日简报和晚上的收尾提醒。
- **Telegram Companion**（[`telegram-companion`](https://github.com/MatsuriMW/telegram-companion)）：见上一节。
- **任务状态快切**（[`task-toggle`](https://github.com/MatsuriMW/Obsidian-Plugins/tree/main/task-toggle)）：⌘/ 在 无 → TODO → DOING 时间 → DONE 时间段 之间切换，自动写上开始和完成的时刻。
- **块去向**（[`done-to-top`](https://github.com/MatsuriMW/Obsidian-Plugins/tree/main/done-to-top)）：把日记里的任务按 DONE / DOING / TODO 分区归位，没做完的整块发送到明天。`⌥⌘S` 把一块发给 Claude CLI 并在下面记上 `🔗`：选中几块并列的，每块各开一个会话；选「子块各开一个」，母块当共同背景，每个子块一个会话。会话跑在哪儿在它的设置里选：终端窗口、后台的 tmux（桌面上不弹窗口，想看再 `tmux attach`）、或者 `claude -p` 无头。

## 快捷键

默认都在 ⌃⌥ 下面，Obsidian 设置 → 快捷键里搜「螺旋日程」可以改。记不住就按 **⌃⌥S** 打开快捷面板：所有操作都在里面，打几个字就能找到，右边写着各自的快捷键；当下用不了的（比如没在专注时的「结束这一轮」）不会出现。

| 快捷键 | 做什么 |
|---|---|
| ⌃⌥S | 快捷面板：螺旋日程的所有操作 |
| ⌃⌥V | 现在怎样：一块面板。最上面是时刻和今天过了多少；三块数字是已计划、余量 / 超载 / 空档不足、剩余百分之几；下面是在做的（计时每秒走）、专注和吃饭 / 锻炼、接下来几件和它们排到的时刻、排不下的、搁置的；最后是今天做完几件、复盘偏差、Agent 协作。点任意一行跳到日记里那一行；底下一排按钮是开始下一件、打开螺旋、整理进日记、Agent 会话 |
| ⌃⌥C | 正在做的事的 Agent 会话：每件 DOING（和这一轮专注里的）期间看起来相关的会话；只是时间重叠的收在「同一时段的其它会话」里；最后是现在还在跑、没对上哪件的会话。Claude 和 Codex 的会话能一键回去 |
| ⇧⌘↵ | 开始光标所在的任务（改成 DOING + 专注） |
| ⌃⌥N | 开始下一件 |
| ⌃⌥F | 开一轮专注（选一个大方向） |
| ⌃⌥E | 结束这一轮专注（问做完了没有） |
| ⌃⌥B | 吃饭 / 锻炼回来了（问要不要切回 DOING） |
| ⌃⌥R | 预估 vs 实际：打开螺旋，展开并滚到复盘那一块 |
| ⌃⌥O | 打开螺旋日程 |
| ⌃⌥T | 设置今天的起床 / 收工时间 |

另外还有两条没设快捷键的命令：「打开今天的日记（凌晨按日界算前一天）」「重新读取日历（macOS 日历 / Google 日历）」。
